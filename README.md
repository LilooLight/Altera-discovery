# МИС Альтера — Бренд-бук

Презентация-бренд-бук для Медицинской Информационной Системы «Альтера».

## Содержание

14 слайдов 16:9 (1280×720):

1. **Титульный слайд** — обложка с биофильным фоном
2. **Философия и позиционирование** — характер бренда
3. **Фирменный знак** — логотип и правила
4. **Охранное поле** — защитная зона, размещения
5. **Цветовая палитра UX** — пропорции 60/30/10
6. **Семантика цвета и полиграфия** — статусы + CMYK/Pantone
7. **Типографика** — Playfair Display + Inter
8. **Биофильный стиль иллюстраций** — 3 принципа
9. **Полиграфия и материалы** — тактильность
10. **Бланки, визитки и идентификация**
11. **UI-Kit: Кнопки и состояния**
12. **UI-Kit: Данные и графики** (тёмная тема)
13. **Коммуникационный тон (Tone of Voice)**
14. **Заключение** — спасибо за внимание

## Файлы

| Файл | Описание |
|---|---|
| `MIS_Altera_Brandbook.pptx` | Готовая презентация PowerPoint (1.8 МБ) |
| `source_html/` | HTML-исходники слайдов (1280×720) + `global.css` + `slides_brief.json` |
| `source_html/bg_cover.jpg`, `source_html/bg_closing.jpg` | Биофильные фоны обложки и закрытия |

## Дизайн-система

- **Палитра:** Tiffany `#5ECEC1` · Золото `#C9A96E` · Чаркоул `#1A1F2E` · Беж `#F5EFE6`
- **Шрифты:** Playfair Display (заголовки) + Inter (текст)
- **Стиль:** Neomorphism + Biophilic + Glassmorphism
- **Тема:** Смешанная (светлая по умолчанию, тёмная на слайде 12)

## Как пересобрать .pptx из HTML

```bash
NODE_PATH=/usr/local/lib/node_modules node /home/z/my-project/skills/pptx/batch_html2pptx.js \
  /path/to/source_html \
  /path/to/output.pptx
```
